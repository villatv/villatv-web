Condiciones del Servicio

Última actualización: octubre de 2026

1. Descripción

VillaTV ScoreBOX es una herramienta privada utilizada para la producción y operación de transmisiones deportivas realizadas por VillaTV.

La aplicación puede integrarse con servicios externos, incluyendo YouTube API Services, para facilitar la gestión y supervisión de transmisiones en vivo.

2. Uso autorizado

ScoreBOX está destinado al uso de VillaTV y de operadores expresamente autorizados.

El usuario es responsable de las acciones que realiza mediante la aplicación, incluyendo iniciar o finalizar transmisiones y seleccionar contenido para mostrar durante una emisión.

3. YouTube

Al utilizar funciones de ScoreBOX que acceden a YouTube API Services, el usuario también acepta quedar sujeto a las Condiciones del Servicio de YouTube .

El uso de información proporcionada por Google y YouTube también se encuentra descrito en nuestra Política de Privacidad.

4. Control sobre las acciones

Las acciones que modifican el estado de una transmisión, como comenzar o finalizar un vivo, requieren una acción expresa del operador.

ScoreBOX no está diseñado para iniciar o finalizar automáticamente una transmisión sin intervención del operador.

5. Disponibilidad

ScoreBOX se proporciona como una herramienta operativa y puede depender de servicios externos, conexión a Internet, APIs de terceros y disponibilidad de los sistemas utilizados por VillaTV.

No se garantiza que todos los servicios externos estén disponibles de forma ininterrumpida.

6. Cambios

Las funciones y estas condiciones pueden actualizarse cuando evolucione ScoreBOX o cambien los servicios externos utilizados por la aplicación.

7. Contacto
